## Why this scale

Phase 1 estimated about 150 originals with very many compositions. This plan approves about 130 entries: almost all are configurations and templates, because the style is procedural by nature. Its diversity is compositional: 20 layouts x 11 families x 11 grids, with the review rule that a layout must look like a different poster.

## Families

### KON-GEO-CIR Circle choreographies (6 configurations)

- **Purpose:** Circle sequences: the most versatile family.
- **Design language:** Flat geometric forms on the grid, quantised motion in steps with crisp ease-out; one form family per choreography; forms align to grid modules or their halves.
- **Production:** authored-data; JSON choreography: form type, count, module placement rule, step sequence (what changes per step), step trigger source, ease.
- **Dimensions:** Grid modules (resolution independent).
- **Variation dimensions inside the family:** member identity only (each member is a different design)
- **Compatibility:** Grids and layouts; colour systems; timing sources. **Exclusions:** Op-art density limits: no more than 6 alternating stripes per 10% of frame width, contrast of alternating forms under 3:1 when moving.
- **Quality bar:** Reads as structured rhythm (not decoration) with and without a beat grid; never crosses the type block; passes the flicker check.

### KON-LAY-GRD Grid systems (11 components)

- **Purpose:** The structure every poster is built on.
- **Design language:** Modular grids with margins, columns, rows and a baseline.
- **Production:** authored-data; JSON grid spec (columns, rows, gutter, margins, baseline) per aspect class.
- **Dimensions:** Normalised.
- **Variation dimensions inside the family:** member identity only (each member is a different design)
- **Compatibility:** All layouts. **Exclusions:** Radial grid only with concentric layouts.
- **Quality bar:** Modules square or 2:3 at all sizes; margins at least 6%.

### KON-LAY-LAY Layout templates (19 components)

- **Purpose:** Structure is the variation: each template is a different poster.
- **Design language:** Specific slot arrangements per composition family.
- **Production:** authored-data; JSON: slots (type, dominant form, secondary, numerals) in module coordinates, exclusion masks.
- **Dimensions:** Modules.
- **Variation dimensions inside the family:** member identity only (each member is a different design)
- **Compatibility:** Grids listed per template. **Exclusions:** Templates declare scripts they support.
- **Quality bar:** Reads as a designed poster in a still; solver places type without collisions at 4 sizes.

### KON-PAL-PAL Colour systems (10 configurations)

### KON-TEX-TEX Print textures (6 sources)

- **Variation dimensions inside the family:** member identity only (each member is a different design)
- **Compatibility:** Paper systems. **Exclusions:** Not with negative print.
- **Quality bar:** Invisible as a pattern; no tiling.

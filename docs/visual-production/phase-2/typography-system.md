# Typography system

Phase 2 planning. The shared typography infrastructure, the script rules every style follows, and the typeface list. Tables are generated from the style data and the shared manifest by `docs.py`.

## 1. Infrastructure (planned, batch INF-07)

- **Script detection per run** using the existing `lib/lyrics/script.ts`. A line is split into runs by script (Latin, Devanagari, Tamil, Arabic, Hebrew, CJK, other).
- **Face routing.** Each style declares faces per role and per script (`styles/<slug>/typography.md`). The router picks the face for each run and role; missing scripts fall back through the style's chain, then to the Noto family of that script, then to the system stack (declared, never silent).
- **Shaping.** Complex scripts are shaped by the browser (Canvas `fillText` or DOM measurement) and treated as whole shaped runs. No style splits a Devanagari, Tamil or Arabic word into letters.
- **Per-letter effects** (rotation, jitter, per-letter reveal, flap per character) apply to Latin, Greek and Cyrillic only, and to CJK per character where the style says so. Complex scripts get whole-word or whole-run effects: wipes along the reading direction, word fades, whole-word scale.
- **Right-to-left.** Arabic and Hebrew runs reverse reading-direction behaviour: wipes run right to left, layouts mirror where the style says so, Panels pages read right to left.
- **Metrics and wrapping.** Wrapping is at word boundaries for all scripts (grapheme-cluster safe); line height is per face (Devanagari and Tamil need taller line boxes, about 1.35-1.5 of the Latin value).
- **Payload budget (V14).** Fonts load per style, on demand, as WOFF2 subsets by script. Target: the Latin faces of one style under 300 KB; each extra script subset loaded only when the song contains that script.
- **Licences.** Every face is a dependency entry in the shared manifest with its licence. Faces marked "verify" are checked in batch SHR-B1 before use.

## 2. Rules every style follows

1. Active lyric text at least 4.5:1 contrast against what is directly behind it.
2. Minimum active-text size: 3% of frame height for body roles, larger where the style says so.
3. No faux bold, faux italic or synthetic stretch on complex scripts. Italic voices fall back to upright for scripts without italics.
4. Mixed-script lines use matching weights across runs (the style's face table pairs them).
5. Hardware or stroke styles (Signage dot matrix, Phosphor stroke fonts, Monument mesh extrusion) declare which scripts they cannot draw and route those lines to a declared fallback rendition.
6. Native readers review special script renderings (neon Devanagari and Tamil, Ink stroke reveal, Phosphor outline trace, Monument sprite stacks) before approval.
